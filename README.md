学校のCG課の期末課題で、UnityのTileMap機能を使って、ゲームのシーンに自分で作った素材や無料素材を組み込む練習をしました。

先生が用意してくれた素材には、簡単なキャラクターの移動スクリプトとシーン切り替えスクリプトしかなく、背景やアニメーションはありませんでした。そこで、自分で作成したキャラクターに置き換え、itch.ioからダウンロードした無料素材を追加し、シーンをデザインしました。上下に移動するプラットフォームやコインを集めるシステム、タイマーシステムを導入しました。キャラクターの移動やジャンプなどのアニメーション効果を追加し、背景を複数のレイヤーに分け、それぞれの移動速度を変えることで奥行きを表現しました。

For the final project in my school's CG class, we practiced using Unity's TileMap feature to incorporate both self-created and free assets into a game scene.

The teacher's materials only included a simple character movement script and a scene transition script, with no background or animation effects. I replaced the character with one I created myself, added free assets downloaded from itch.io, and designed the scene. I also implemented platforms that move up and down, a system for collecting coins, and a timer system. I added movement and jump animations for the character and layered the background with different scrolling speeds to create a sense of depth.
